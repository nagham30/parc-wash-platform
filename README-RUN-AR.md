# تشغيل منصة المياه والصرف الصحي وتعزيز النظافة

هذه نسخة معدلة من مشروع Figma Make الأصلي (React + Vite + Tailwind CSS).

## المتطلبات
- Node.js 22 أو أحدث
- اتصال بالإنترنت **أول مرة فقط** لتثبيت الحزم

## التشغيل محليًا
1. فك الضغط وافتح المجلد في VS Code.
2. افتح Terminal داخل المجلد.
3. نفّذ:

```bash
npm install
npm run dev
```

4. افتح الرابط الذي يعرضه Vite، غالبًا `http://localhost:5173`.

## تجهيز نسخة للنشر
```bash
npm run build
```
سيتم إنشاء مجلد `dist` إذا نجح البناء.

## ملاحظات مهمة
- تسجيل الدخول الحالي **واجهة تجريبية** وليس مصادقة آمنة؛ لا تنشر لوحة الإدارة كخدمة حقيقية قبل إضافة Backend وصلاحيات.
- بعض أزرار التحميل لا تحتوي ملفات PDF فعلية في المصدر؛ تعرض رسالة بدل تحميل ملف غير موجود.
- بيانات الإدارة محفوظة محليًا في المتصفح، وليست قاعدة بيانات مشتركة.
- الصور الخارجية الموجودة أصلًا في المشروع تعتمد على روابط Unsplash وقد تحتاج اتصالًا بالإنترنت.
- لم يتسن تنفيذ npm install / npm run build في بيئة الإعداد بسبب تعذّر تنزيل الحزم؛ يجب اختبار البناء على جهازك.
