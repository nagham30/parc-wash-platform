# إضافة المراسلات الداخلية — PARC WASH

## ما تم تعديله
- صفحة `#/admin/messages` في لوحة الإدارة، فيها وارد ومرسل وكتابة رسالة وعلامة مقروء.
- قائمة المستلمين تقتصر على المدير ومساعد المدير عبر دالة آمنة في Supabase.
- إضافة رابط المراسلات إلى القائمة الجانبية.

## تشغيل التحديث
1. في Supabase > SQL Editor > New query: افتح `supabase/sql/03_internal_messages.sql` والصق محتواه ثم Run.
2. فك ضغط النسخة الجديدة. **انسخ ملف `.env.local` من المشروع القديم** إلى مجلد `hygein` بجوار `package.json`؛ الملف الخاص غير مضمّن في ZIP.
3. افتح مجلد `hygein` في VS Code وشغّل `npm install` ثم `npm run dev`.
4. سجّل الدخول كمدير وافتح «المراسلات الداخلية» من القائمة الجانبية.
5. أرسل رسالة إلى مساعد المدير بعد تفعيل حسابه، ثم افتح حسابه للتأكد من وصولها.

## ملاحظات
- لم نتمكن من إجراء اختبار بناء كامل داخل بيئة Linux لأن ملف ZIP احتوى مكتبات `node_modules` الخاصة بويندوز؛ لذلك يجب اختبار `npm run build` على جهازك.
- ملف SQL يعيد إنشاء سياسات الرسائل القديمة بطريقة مقيدة، ويحتاج التنفيذ مرة واحدة.
- هذه المرحلة للمراسلات فقط؛ الإشعارات الفورية ونظام الموافقات لم تُنفّذ بعد.
