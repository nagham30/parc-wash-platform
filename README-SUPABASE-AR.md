# المرحلة الأولى: تسجيل الدخول والصلاحيات

1. افتحي مشروع Supabase → Project Settings → Data API وانسخي Project URL.
2. انسخي `.env.example` إلى `.env.local` في نفس مجلد `package.json`.
3. اكتبي `VITE_SUPABASE_URL` و `VITE_SUPABASE_PUBLISHABLE_KEY` (المفتاح العام فقط).
4. شغلي `npm install` ثم `npm run dev`.
5. افتحي `#/login` وسجلي الدخول بحساب المدير الذي أُنشئ في Supabase.

النسخة تحمي مسارات الداشبورد على مستوى واجهة المستخدم، وتقرأ الدور من `public.user_roles` باستخدام حساب المستخدم الحالي. حماية البيانات الفعلية تعتمد على RLS وقواعد الصلاحيات في Supabase، وليس على إخفاء الصفحات. **إدارة الأنشطة والدورات والمكتبة ما زالت تستخدم localStorage، وليست مربوطة بعد بقاعدة البيانات.** المراسلات والموافقات والإشعارات وسجل العمليات لم تُربط بعد بالواجهة. لا تنشري النسخة كمنتج جاهز قبل اكتمال ذلك واختبار سياسات RLS.
